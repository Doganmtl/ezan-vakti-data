# kota-defteri (otomatik dal)
Kalıcı defterler (D23, `KOTA-ANALIZI.md`). Elle düzenlenmez; yalnız `scripts/defter-dali.sh kaydet` yazar.
- `awqat.json` — kullanıcının operasyonel günlük 100 HTTP sınırı (D16): giriş, yenileme, Quota/My ve başarısız istekler dahil.
- `awqat-kota.json` — Diyanet servis kotası: gün/ay/yıl × `hizmet` ve `hizmet|parametre` (giriş, yenileme ve Quota/My hariç).
